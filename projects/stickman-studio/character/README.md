# Packet Guy V1

Canonical mascot for the stickman/tech-explainer project.

## Locked identity
- Light-brown South Asian / British-Bangladeshi appearance
- Messy black hair, light scruffy stubble
- Black cap, oversized black hoodie, dark cargos, white/grey sneakers
- Cyan is the only accent colour
- Curious, tired, slightly sarcastic, expressive

## Asset rules
- Use the same character proportions and clothing across every episode.
- Do not regenerate a new “similar” mascot for each video.
- Reference art is for consistency; animation assets may be simplified.
- Keep the palette minimal and avoid generic glossy AI styling.
