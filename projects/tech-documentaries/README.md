# Tech Documentaries

One folder per documentary.

Example:

```text
projects/tech-documentaries/dart/
projects/tech-documentaries/jeep-remote-hack/
projects/tech-documentaries/hypersonic-test/
projects/tech-documentaries/apollo-13/
```

These projects can use `engine-v4/` for reconstruction systems while keeping story-specific code and timing local to the project.

Current projects include:

- `nasa-1984-controlled-impact/` — completed NASA / FAA Boeing 720 Controlled Impact Demonstration V4 handoff, exact render scripts, asset manifest and takeover notes.
