# Vehicle Explainer Format V1

## Visual modes

**Standard** — vehicle top, kinetic caption middle, Packet Guy lower third. Default explanatory state.

**Statistic** — number/metric owns the composition; vehicle becomes supporting context.

**Technical** — component or diagram becomes primary; use arrows/labels only to explain a real relationship.

**Reaction** — Packet Guy becomes materially larger for surprise, absurdity or a failure beat. Use sparingly.

**Comparison** — A/B, before/after or old/new. Prefer one clean axis of comparison.

**Hero** — real footage or exceptional vehicle image. Reserve for payoff so it feels expensive.

## Motion language

Pose swaps + small transforms beat full character animation. Default micro-motion: 1–3% breathing, 3–8 px bob, spring entrances, 20–40 px vehicle drift, 2–5% emphasis punch. The system should remain legible with motion disabled.

## Caption contract

1–4 words per event. Event cadence target: 0.5–1.2s. Use cyan only for the key noun/technical idea, warning red only for a danger/failure beat, and vehicle-specific accent sparingly.

## Episode structure

QUESTION → EXPLANATION → SURPRISING FACT → MECHANICAL VISUAL → ESCALATION → PAYOFF.

For every spoken phrase ask: **what visibly changes when the viewer hears this?** If the answer is nothing, the beat is unfinished.
